## About

I'm a software engineer from **Gujarat, India**, finishing a Computer Engineering degree — and building products that are meant to be deployed, not demoed. My work sits where **AI systems meet product engineering**: Python/FastAPI services, React/Next.js interfaces, Postgres data models, and LLM pipelines that have to behave under real load.

The two projects I'm proudest of take opposite approaches on purpose. **FairLens** lets five agents reason freely, then audits their reasoning for bias in real time. **YojanaSaathi** keeps LLMs away from the decision entirely, because eligibility should be deterministic. Both come from the same principle: know exactly where intelligence belongs, and where it doesn't.

- 🔭 &nbsp;**Building** — multi-agent AI products with FastAPI, React and Google ADK
- 🧠 &nbsp;**Exploring** — evaluation loops, bias auditing, reliable LLM orchestration
- 🎯 &nbsp;**Open to** — SDE / AI engineering roles and serious open-source work
- 📬 &nbsp;**Reach me** — [sargarapremrajesh@gmail.com](mailto:sargarapremrajesh@gmail.com)

### FairLens

*Multi-agent hiring panel with real-time bias auditing*

<a href="https://fairlens-verdict.vercel.app"><img src="https://img.shields.io/badge/Live_Demo-0D1117?style=flat-square&logo=vercel&logoColor=58A6FF" alt="FairLens live demo" /></a>
<a href="https://github.com/PREMRAJESH/Fairlens"><img src="https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white" alt="FairLens source code" /></a>

Three expert agents evaluate a candidate in parallel. A fourth watches their reasoning and flags cognitive bias **mid-sentence**. A fifth synthesises a debiased verdict.

- **Parallel ADK panel** — three independent opinions, no shared context
- **Inline bias auditor** — 8 bias classes with severity and corrective reframes
- **Live SSE stream** — tokens, flags and verdicts render as they happen
- **Provider fallback** — Gemini → Grok → Groq, so the demo never dies

`Python` `FastAPI` `Google ADK` `Gemini 2.5` `React 19`

### YojanaSaathi

*Open-source welfare-scheme engine for India*

<a href="https://yojana-saathi-seven.vercel.app"><img src="https://img.shields.io/badge/Live_Demo-0D1117?style=flat-square&logo=vercel&logoColor=58A6FF" alt="YojanaSaathi live demo" /></a>
<a href="https://github.com/Yojana-Saathi/Yojana-Saathi"><img src="https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white" alt="YojanaSaathi source code" /></a>

One citizen profile becomes a ranked, auditable catalog of **1,000+ central and state schemes** — with document-gap analysis and draft applications.

- **Deterministic eligibility** — pure Python rule engine, no LLM verdicts
- **OCR document vault** — extracts Aadhaar / income / caste fields and flags gaps
- **Instant drafting** — pre-filled application letters for any matched scheme
- **Production posture** — 121 tests, Postgres RLS, JWT auth, CI/CD

`FastAPI` `Next.js 16` `Supabase` `PostgreSQL` `Groq`
